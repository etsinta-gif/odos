## How to add a new IMP

1. Create a new `IMP-X.X.md` file in this folder.
2. Add related reference document links to the top of the file.
3. Update `docs/implementation/README.md` if the new pack changes the implementation workflow.
4. Keep `docs/reference/` updated with any supporting architecture or standards documents.
