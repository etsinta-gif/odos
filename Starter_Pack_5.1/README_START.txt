=============================================
SPRINT 5.1 STARTER PACK
=============================================

This is the starter pack for Sprint 5.1 – Master Data Management (UI & API).

PREREQUISITES:
- Phase 1-4 completed (backend, APIs, database)
- All MST_* tables exist (MST_Customer, MST_Lender, MST_Product, MST_Employee, MST_Connector)
- FastAPI server runs

WHAT YOU WILL BUILD:
- UI screens to manage Customers, Lenders, Products, Employees, Connectors
- List, Create, Edit, View, and Soft Delete functionality

STEPS:
1. Copy ALL files and folders from this pack into your odos project root
2. Follow IMP-5.1.md step by step
3. Start the server and test at http://localhost:8000/masters/customers

FILES INCLUDED:
- src/masters/api/*.py        (Backend API endpoints for each entity)
- src/masters/ui/routes.py    (UI routes that render HTML templates)
- src/templates/masters/*.html (HTML templates for list and form pages)
- src/static/css/style.css    (Basic styling)
- scripts/seed_test_data.py   (Optional script to populate test data)

ESTIMATED DURATION: 2–3 days
CONTACT: CTO or Technical Programme Manager
