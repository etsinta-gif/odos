=============================================
SPRINT 5.2 STARTER PACK
=============================================

This is the starter pack for Sprint 5.2 – Case Management (UI & API).

PREREQUISITES:
- Sprint 5.1 completed (Master Data Management UI)
- MST_Customer, MST_Lender, MST_Product tables populated
- TRN_Case and TRN_CaseStatusHistory tables exist

WHAT YOU WILL BUILD:
- UI screens to manage Cases (Loan Applications)
- List, Create, Edit, View, and Status Transitions

STEPS:
1. Copy ALL files and folders from this pack into your odos project root
2. Follow IMP-5.2.md step by step
3. Start the server and test at http://localhost:8000/masters/cases

FILES INCLUDED:
- src/masters/api/case.py       (Case CRUD + status API)
- src/masters/ui/routes.py      (UI routes – you will ADD new routes)
- src/templates/masters/*.html  (Case list, form, detail)
- scripts/seed_test_cases.py    (Optional test data)
- TEST-5.2.md

ESTIMATED DURATION: 2 days
