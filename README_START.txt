SPRINT 1.1 STARTER PACK

This is the starter pack for Sprint 1.1  Project Skeleton & Development Environment.

PREREQUISITES:
- Python 3.12+ installed
- Docker Desktop installed
- Git installed

STEPS:
1. Unzip this folder into your project root (odos/)
2. Install uv: curl -LsSf https://astral.sh/uv/install.sh | sh
3. Run: uv sync
4. Copy .env.example to .env and update values
5. Run: docker-compose -f docker/docker-compose.yml up -d
6. Follow IMP-1.1.md for implementation tasks

ESTIMATED DURATION: 5-7 days

CONTACT: For questions, reach out to the CTO or Technical Programme Manager.
